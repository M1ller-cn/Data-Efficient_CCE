# Data access

This repository does not redistribute source measurement tables.  Download the
two public sources from their original records before running any script:

1. **CALiSol-23**: the Scientific Data article and its associated data record.
2. **Robotic conductivity collection**: Zenodo record `10.5281/zenodo.7244939`.

Set `--calisol-csv` and, where relevant, `--external-csv` to local copies of
those tables.  Derived split indices, result CSVs, and figures generated for a
released manuscript version are deposited under a tagged GitHub release rather
than committing third-party raw data here.

Do not upload a source table unless its licence explicitly permits
redistribution and the release retains the source attribution and licence.
